# 小手机 v0.1.0

这是第一阶段的界面测试版，暂名「小手机」。不需要填写密钥，不调用模型，不生成或修改聊天正文。

## 本次可以测试

- 安装后出现可拖动的悬浮入口；点击打开或收起手机。
- 酒馆扩展栏中的「小手机」条目：显示/隐藏入口、打开手机设置、重置入口位置。
- 手机桌面，以及电话、短信、Snapchat、X、Amazon 的空页面。
- 电话页面底部的「电话」「联系人」标签。
- 手机设置中的五个分类页：外观、API、App 管理、提示词、失败重试。
- 深浅色主题、四种壁纸、字号和窗口宽度；窄屏自动适配。
- App 关闭后图标消失，重新开启后回来；设置图标始终保留。
- 分功能编辑提示词，自动保存，单项恢复默认。
- 重试次数只能填写 0—15 的整数，0 为关闭自动重试；不含首次请求。
- 设置及悬浮位置保留，刷新后恢复。

## 还没有接入

AI 回复、正文读取、电话号码识别、好友/账号修改、真实未读角标、来电与通话、商品订单、剧情时间、剧情记忆及删楼回退。App 页面会明确显示「页面预留」。API 页暂时说明使用酒馆连接，独立 API 将随通信模块加入。提示词和重试设置现阶段仅保存，后续生成模块接入后使用。

桌面当前显示设备时间，标有「设备时间」，未把它当成剧情日期。

## 先看免安装预览

下载仓库中的 [preview.html](preview.html)，使用浏览器打开；不需要启动酒馆，也不需要联网。此前提供的 pocket-phone-preview.html 和压缩包中的「界面预览.html」也是同一版本。

预览设置与酒馆设置相互独立。在某些手机文件预览器中 JavaScript 或本地储存不可用，请选择「用浏览器打开」。不能用文件预览器的显示结果判断酒馆安装是否成功。

## 从私有 Git 仓库安装

仓库地址：`https://github.com/ppisa386-png/pocket-phone.git`，默认分支 `main`。

这是私人开发仓库。运行酒馆的 Termux 需要先获得此仓库的 Git 读取权限，手机浏览器中登录 GitHub 不会自动完成这一步。请勿把密码或访问令牌写进仓库、代码、截图或聊天内容。

完成 Termux 的 Git 认证后，在酒馆「扩展 → 安装扩展」中填写上述地址，分支使用默认值，完成后刷新页面。具体认证方式按实际酒馆版本及 Git 后端确认。后续版本会继续上传到同一仓库，安装后的扩展可通过酒馆的扩展更新功能获取更新。

若此前已手动安装同名 ZIP 版本，先确认该目录是否已包含 Git 信息；不要把仓库再装到另一个目录形成重复插件。

## 使用先前 ZIP 包手动安装

本包是 ZIP，不是 Git 仓库网址，不能把 ZIP 路径填入酒馆「安装扩展」的地址框。

1. 解压安装包，找到完整的 `pocket-phone` 文件夹。
2. 找到运行酒馆的设备上的 SillyTavern 程序文件夹。浏览器访问的服务器如果不在本机，要在服务器上放文件。
3. 通常可放在 `SillyTavern/data/你的账号目录/extensions/pocket-phone/`。默认账号目录通常是 `default-user`；以你实际目录为准。也可使用全局目录 `SillyTavern/public/scripts/extensions/third-party/pocket-phone/`，两处选一处，不要重复安装。
4. 确认 `manifest.json` 和 `index.js` 直接位于 `pocket-phone` 中，避免套成 `pocket-phone/pocket-phone/manifest.json`。
5. 刷新酒馆页面。如果仍未发现，重启酒馆后再刷新。在扩展栏检查「小手机」条目及屏幕上的悬浮按钮。

不需要打开或修改任何代码文件。如果你在安卓一键启动器、Termux、容器或托管服务器中运行酒馆，而无法找到上述目录，请把运行方式告诉制作者，再给你对应的安装步骤，不必猜目录。

手机窗口里点右上角 × 收起；底部横条回桌面。隐藏入口后，可从「酒馆扩展 → 小手机 → 打开手机设置」重新打开。

## 建议反馈的五件事

1. 能否出现、拖动、隐藏并找回悬浮入口？
2. 窗口、字号和按钮是否适合你的屏幕？是否有被遮挡的部分？
3. App 关闭和重新开启是否正常？
4. 提示词修改、主题等在刷新后是否保留？
5. 重试次数填 0、15、16 时是否正确保存或拒绝？

出现问题时提供截图、酒馆版本、手机/电脑与浏览器，以及出错前的操作即可。

## 技术说明

无第三方运行依赖，不修改酒馆核心文件。通过 `SillyTavern.getContext()` 读取/保存插件全局设置；手机使用 Shadow DOM 隔离样式。首版不写 chatMetadata、不读取角色卡、不监听剧情变化。不会存储 API 密钥。

参考接口文档：https://docs.sillytavern.app/for-contributors/writing-extensions/

源码、测试和预览生成脚本包含在文件夹内。`node --test tests/config.test.js` 可运行配置测试；`python3 tools/build_preview.py` 可从同一套 UI 源码重新生成离线预览。

这是独立编写的实现，未复制参考手机项目的源代码或界面素材。
