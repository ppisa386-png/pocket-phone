- 正式版本为 1.2.36。天气 UI 当前在 `src/weather-view.js`；天气引擎和剧情联动在 `src/weather.js`；天气图标及背景资源选择在 `src/weather-art.js`。

- 天气数据、天气状态、逐小时/七日预报、预警、城市位置、天气种子与剧情时钟均由现有 `src/weather.js` 管理；本次原则上只改 UI、样式和素材打包，不新增 API/模型请求、不更改天气模拟与回退语义。
- 当前样式集中于 `style.css`。改造时应整理天气专属 CSS，避免新增规则污染其他 App 或主题；入口 `index.js` 当前读取 `style.css`，需根据实际实现决定是否新增独立 CSS 以及同步预览构建器。
- 需要进一步审查当前 warning 数据模型是否支持同一时刻多个有效预警；如果引擎只输出一个 warning，先在不改变生成机制的前提下确认已有数据结构，再实现 UI 展示，不得虚构预警。

## 已确认视觉规范

### 风格与色彩

清新、精致、轻奶油、手绘绘本、轻可爱；水彩/粉彩窗景与现代信息排版结合。避免摄影背景、玻璃拟态、大面积渐变、厚重阴影、反复堆叠大卡片、花边装饰和过度可爱化。天气数据优先，插画为辅助视觉。

- 页面背景：`#FDF4EB`
- 主要内容底色：`#FFFBF5`
- 次级区域：`#F7EFE4`
- 主文字：`#46545E`
- 次级文字：`#85867F`
- 辅助文字：`#A49B90`
- 分隔线：`#E9DDD0`
- 天空蓝：`#8DB9E2`；雾蓝：`#AFC4D6`；奶油黄：`#F4D579`；花朵粉：`#EAA5A8`；植物绿：`#91A96F`；木窗棕：`#D9975E`。

### 字体

- 英文及数字：Manrope；中文：Noto Sans SC。
- 通过 Fontsource 本地打包，优先 variable 字体及必要字符集；不依赖运行时远程字体服务器。
- 当前温度 Manrope 300、56–64px（窄屏 50–56px），tabular numerals；城市/标题适度 500；辅助文字 400；不要浏览器合成缺失字重。

### 首屏与插画

- 左侧天气信息约 58–60%，右侧插画约 40–42%。
- 360px 内容宽时，插画显示宽度约 110–126px，保持原始 4:5 比例；窄屏优先缩小插画与间距，不挤压温度/天气描述。
- 左侧展示城市、日期、当前温度、天气描述、体感温度、今日高低温；左右两侧留有呼吸空间，不贴面板边缘。
- 五张原图只使用用户提供的附件，不重新生成、不用第三方素材替代。映射：Sunny→晴/晴间多云；Cloudy→多云/阴天；Rainy Day→小雨/中雨/大雨/雷雨/暴雨/台风；Snowy→小雪/中雪/大雪；Good Night→晴朗夜间。雨夜优先 Rainy；雾霾暂用 Cloudy；夜间多云依实际状态决定。
- 优先尝试精细抠出窗景透明主体；如白色窗帘、花朵边缘产生白边/锯齿，则使用与原画布一致的奶油底色融合。不得粗暴抠图破坏原画。保留高清母版，页面使用清晰的本地 PNG/WebP。

### 页面顺序与组件

页面顺序固定为：顶部城市栏 → 主天气信息与天气窗 → 当前有效预警（有则显示，无则完全隐藏）→ 24小时天气 → 未来七天 → 天气指标。

- 预警必须在插画下方、24小时预报上方；保留蓝Ⅳ、黄Ⅲ、橙Ⅱ、红Ⅰ四级颜色及现有判断逻辑。预警使用真实的剧情模拟数据，不宣称官方实时预警；多条有效预警全部展示。
- 24小时预报继续横向滑动，时间/图标/温度紧凑呈现，不使用厚重卡片；当前时刻仅轻量高亮。
- 七日预报采用纵向列表：星期/日期、图标、天气描述、低温、共享温度范围条、高温；保留极端天气提示。
- 指标区 2列×3行：体感、降水、风力、湿度、UV、AQI；轻量分隔线、细线图标、可保留既有详情交互。

### 适配与动效

- 小窗宽度 280–640px、高度 460–1200px；无横向溢出，纵向内容滚动，逐小时横向独立滚动。
- 主天气信息优先，窄屏依次缩小插画、内边距，必要时温度字号降至 50–56px；避免温度贴边或天气描述不自然换行。
- 夜间仍用同一浅色基础页面，不按昼夜切换深色主题。
- 插画淡入 200–250ms；刷新轻旋转；点击轻按压；不持续漂浮/摇晃、不加粒子；尊重 prefers-reduced-motion。
