# 微信 RNWeChat 复刻与音乐分享素材

UI 参考：https://github.com/yubo725/rn-wechat （dev 分支），沿用页面排版、深灰标题、浅灰分组和绿色控件，本插件以 HTML/CSS 重现，不导入 React Native 或其服务。

音乐卡片的彩色 CD：Microsoft Fluent UI Emoji，`assets/Optical disk/Flat/optical_disk_flat.svg`。来源：https://github.com/microsoft/fluentui-emoji ，MIT，随插件已有完整授权见 `assets/food/LICENSE-fluentui-emoji.txt`。

无外部网络素材请求。音乐只有歌曲分享元数据和文字说明，不提供真实音乐流媒体播放。
