# 榴莲外卖本地视觉素材来源

## Fresh Bite V2.0 · 当前页面使用

- `illustrations/*.svg` 中的 hamburger、shortcake、pizza、sushi、spaghetti、taco、burrito、sandwich、croissant、doughnut、cupcake、cookie、bread、shrimp、teapot、pancakes、peach：来自 Microsoft Fluent UI Emoji 的 `assets/<Food Name>/Flat/*_flat.svg`；MIT，完整许可 `LICENSE-fluentui-emoji.txt`。
- `illustrations/*.svg` 中的 plate (`1f37d`)、ramen (`1f35c`)、salad (`1f957`)、bento (`1f371`)、chicken (`1f357`)、curry (`1f35b`)、drink (`1f964`)、coffee (`2615`)：来自 jdecked/twemoji 的 `assets/svg/<code>.svg`；CC BY 4.0，许可证 `LICENSE-twemoji-graphics.txt`。Twemoji artwork copyright Twitter, Inc and other contributors；使用时保留此署名。
- 图标沿用项目内 `src/icons.js` 现有描边式 SVG，不运行时依赖外部图标库；设计参考 Lucide。
- https://github.com/microsoft/fluentui-emoji
- https://github.com/jdecked/twemoji
- https://github.com/lucide-icons/lucide
- 全部图片本地引用，不会联网；未知菜品优先回退为通用餐具图。
